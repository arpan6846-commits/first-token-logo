# Wealth Engine AI

A private, single-owner application for managing the owner's own capital (INR 10,000 to start) across Indian stocks (NSE/BSE, cash delivery) and crypto spot (INR markets). It monitors markets, generates rule-based trade candidates using the *prop trading desk* rulebook ("The Language of Price"), checks every order against deterministic risk rules, executes only through authorised broker/exchange APIs, records only verified fills in an append-only double-entry ledger, and compounds only verified, settled, net realized profit.

> **The 10% daily figure is an aspirational target. It is not a guarantee, not a forecast and not an expected return.** No code path increases risk or position size to chase it (enforced by tests). Losses are possible.

No public users, no third-party money, no pooled funds, no advice.

## What's here

| Path | What it is |
|---|---|
| `core/` | The engine: pure TypeScript, no dependencies; runs in Node, Deno and the browser. Ledger, risk engine, order manager, compounding, fee/tax model, prop-desk rulebook, signals, backtest, reconciliation, adapters. |
| `core/adapters/` | Common venue interface + `KiteAdapter` (Zerodha Kite Connect v3), `CoinDCXAdapter` (spot), `PaperAdapter` (paper/simulation). |
| `base44/entities/` | 19 Base44 entity schemas (generated by `scripts/gen-entities.mjs`), owner-read-only RLS, no browser writes. |
| `base44/functions/` | Deno backend functions: `ownerCommand`, `kiteLogin`, `kiteCallback`, `kitePostback`, `workerGateway`, `aiReviewSignal`, `revokeCredentials`, scheduled `watchdog` and `dailyReport`. |
| `base44/shared/` | Shared backend code; `shared/core` is a generated copy of `core/` (`node scripts/sync-shared.mjs`). |
| `worker/` | Persistent Deno worker: WebSocket/REST market feeds, the single writer that executes owner commands, triggers armed signals, places/syncs orders, reconciles, runs the daily close. |
| `frontend/` | React + Tailwind dark UI (13 screens). Local mode runs the real engine in the browser in **simulation**; `VITE_DATA_MODE=base44` reads Base44 entities. |
| `tests/` | 83 automated tests (acceptance, unit, adapters, integration, end-to-end). |
| `docs/` | Status, test results, architecture, compliance, deployment checklist. |

## Run it locally (simulation)

```bash
npm install && npm test              # 83 tests, Node 22+
cd frontend && npm install && npm run dev   # http://localhost:5173
```

In local mode only the **simulation** environment has data (synthetic, seeded prices, always labelled SIMULATED). Paper and production show "not connected" until the Base44 deployment and worker are running. Use the clock buttons (+5m … +1 day) to advance simulated time. On *Stock market → Load scripted rulebook setup* you can inject a textbook setup and walk the whole flow: signal → Final Check → arm → confirmed break → fill → exit → ledger → compounding.
